## 設計原則

### 視覺層次（三區法則）
- **頂部**：Logo 或主要價值主張
- **中部**：支援訊息 + 視覺元素
- **底部**：CTA（按鈕 / QR / URL）

### 安全區域
- 關鍵內容放置於畫布中央 70–80%
- 文字 / CTA 距邊緣至少 50–100px
- YouTube：2560×1440 中的 1546×423 安全區
- Meta / Instagram：中央 80% 以避免 UI chrome 遮蓋

### CTA 規則
- 每個 Banner 只有一個 CTA
- 與背景高對比
- 放置於右下角（視線終點區）
- 手機點擊目標最小 44px 高度
- 使用動詞開頭：「取得」「開始」「下載」「立即」

### 文字排版規範
- 每個 Banner 最多 2 種字型
- Body 最小 16px，Headline 最小 32px（數位）
- 最小對比度 4.5:1
- 廣告文字每行最多 7 個詞，最多 3 行

### 文字 / 圖片比例
- 廣告：文字佔比 < 20%（Meta 超過會降低觸及）
- 社群封面：60% 圖像 / 40% 文字
- 印刷：3–5 公尺觀看距離時標題需 70pt 以上

### 印刷規格
- 最小 300 DPI（大型輸出最小 150 DPI）
- 各邊 3–5mm 出血
- CMYK 色彩模式
- 每英尺觀看距離對應 1pt 字級

## 各平台快速規格卡

### Facebook
```
貼文分享：  1200 × 630px
封面照片：  820 × 312px（桌機）/ 640 × 360px（手機）
限時動態：  1080 × 1920px
```

### Instagram
```
正方形貼文：1080 × 1080px
橫式貼文：  1080 × 566px
直式貼文：  1080 × 1350px（Reels 封面）
限時動態：  1080 × 1920px
```

### Threads
```
建議尺寸：  1080 × 1080px 或 1080 × 566px
```

### YouTube
```
頻道封面：  2560 × 1440px（安全區域 1546 × 423px）
影片縮圖：  1280 × 720px（最小 640 × 360px）
```

### Google Ads 優先順序
```
必做：300×250（Medium Rectangle）
次要：728×90（Leaderboard）、300×600（Half Page）
加強：336×280（Large Rectangle）
```
