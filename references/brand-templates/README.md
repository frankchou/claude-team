| 7 | 元件 / 按鈕 | 互動狀態規格 | 建議 |

## Logo 設計原則

### 核心屬性
一個好的 Logo 必須同時具備：
- **符號性** — 有意義的圖像或隱喻，不是隨機圖形
- **可擴展性** — 在 16px favicon 到 2560px billboard 都清晰可辨
- **獨特性** — 在同類產品中可辨識，不與他人相似
- **策略性** — 視覺語言反映品牌核心隱喻

### Logo 應避免的通用圖示
以下圖示由於過於普遍，應避免作為主要 Logo 元素（除非有高度差異化的執行）：
- 隨機閃電符號（沒有強力理由）
- 隨機動物（不具品牌隱喻）
- 假奢侈品紋章
- 過度複雜的符號
- Clipart 風格圖示
- 無意義的星星 / 閃光
- 複製知名品牌的設計語言

### Logo 概念方法（五種）
1. **字母 + 意義** — 品牌首字母結合隱喻（如「K」+ 方向 / 框架）
2. **產品行為** — 將產品主要動作轉化為符號（build → frame；protect → shield）
3. **隱喻融合** — 兩個有意義概念合併為一個簡化標記
4. **負空間** — 用空白創造智慧感（隱藏箭頭、內部路徑）
5. **構造幾何** — 從清晰的系統建立標記（圓形、對角切割、網格）

### Logo 設計思維框架
設計前先回答：
1. 品牌代表什麼？
2. 核心隱喻是什麼？
3. Logo 如何表達這個隱喻？
4. 如何在 UI、印刷、圖像中擴展應用？
5. 為什麼整體感覺是獨一無二的？

## Logo 各尺寸使用規則

### 版本清單
| 版本 | 檔案命名 | 使用場景 |
|-----|---------|---------|
| 全版橫式 | logo-full-horizontal.svg | 網站 Header、文件 |
| 堆疊版 | logo-stacked.svg | 正方形空間、社群頭像 |
| 僅圖示 | logo-icon.svg | Favicon、App 圖示 |
| 僅文字 | logo-wordmark.svg | 圖示已存在時補充 |

### 色彩版本
| 版本 | 使用時機 |
|-----|---------|
| 全彩 | 白 / 淺色背景預設 |
| 反白版 | 深色背景 |
| 單色深版 | 淺色背景且不可使用彩色時 |
| 單色淺版 | 深色背景且不可使用彩色時 |

### 尺寸規格

**數位最小尺寸：**
| 版本 | 最小寬度 | 說明 |
|-----|---------|------|
| 完整 Logo | 120px | 所有元素可辨認 |
| 圖示版 | 24px | Favicon / 小圖示 |
| 圖示版 | 32px | UI 元素 |

**印刷最小尺寸：**
| 版本 | 最小寬度 |
|-----|---------|
| 完整 Logo | 35mm |
| 圖示版 | 10mm |

### 安全邊距（Clear Space）

### Logo 禁用方式
- 拉伸 / 壓縮比例
- 旋轉或傾斜
- 加陰影
- 應用漸層填充
- 使用未核准顏色
- 加描邊或外框
- 放在繁複背景上
- 裁切任何部分
- 重排元素位置
- 加入額外元素

## 品牌語氣定義方式

### 語氣 vs 音調
- **語氣（Voice）** = 品牌個性（始終一致）
- **音調（Tone）** = 語氣在不同情境的調整（可變）

範例：友善品牌（語氣）在勝利公告時慶祝，在客服回應時同理。

### 品牌個性四個維度
```
正式 ←──────────────────→ 輕鬆
[法律文件]              [社群媒體]

簡單 ←──────────────────→ 複雜
[C 端消費者]            [技術 B2B]

嚴肅 ←──────────────────→ 活潑
[金融]                  [娛樂]

內斂 ←──────────────────→ 表達
[企業]                  [生活風格]
```

### Voice Chart 模板
| 特質 | 我們是 | 我們不是 | 說明 |
|-----|-------|---------|------|
| 自信 | 清晰直接 | 傲慢 | |
| 友善 | 真誠溫暖 | 不專業 | |
| 專業 | 有知識 | 高高在上 | |
| 創新 | 前瞻 | 愛炫技 | |

### 不同情境音調調整
| 情境 | 音調調整 | 範例 |
|-----|---------|------|
| 行銷文案 | 有自信、有鼓動力 | "你會看到改變。" |
| 客服回應 | 更有同理心 | "我們了解您的困擾..." |
| 法律文件 | 更正式 | "依據...條款..." |
| 錯誤訊息 | 有幫助、不責備 | "出了點問題，請試試..." |
| 成功訊息 | 簡短慶祝 | "完成了！" |

### 禁用詞彙（AI Copywriting 陷阱）
以下詞彙是 LLM 生成文案的高頻濫用詞，在品牌文案中禁止使用：
- Elevate / Elevating（提升）
- Seamless / Seamlessly（無縫）
- Unleash（釋放潛能）
- Next-Gen / Next-Generation（下一代）
- Cutting-edge（尖端）
- Leverage（槓桿利用）
- Revolutionize（革命性）
- Transform（轉型，作為空洞形容詞）
- Empower（賦能）
- Best-in-class（同類最佳）
